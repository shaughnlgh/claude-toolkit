# Design Rules Index

This is an index of per-concern rule files under `rules/design/`, each covering one platform gotcha in depth. Open only the concern files relevant to the current task, never the whole catalog.

- `design/mobile-inputs.md` — form fields, touch interaction, or viewport/meta work on anything mobile-facing.
- `design/animation.md` — any motion: transitions, keyframe effects, loaders, reveal/typewriter effects.
- `design/media-loading.md` — images, hero media, or anything affecting LCP/CLS.
- `design/forms.md` — input types, autocomplete, labels, or any form field markup.
- `design/scrolling.md` — modals/drawers, sticky/fixed headers, smooth scroll, or scroll-snap behavior.
